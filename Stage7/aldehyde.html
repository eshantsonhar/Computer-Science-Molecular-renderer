About

This single-file page is a JS + HTML + CSS port of Stage7/aldehyde.cpp. It follows the same parsing flow: tokens separated by '-' are grouped into locant (numbers) and group name pairs, locants are parsed into integer arrays, the parent prefix (meth/eth/prop/...) is searched in the name and objects are produced for bonds, functional groups, halogens and the main parent chain.
