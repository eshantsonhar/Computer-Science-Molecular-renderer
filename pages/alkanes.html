Alkanes

General Formula: CnH2n+2

Saturated hydrocarbons with single bonds only

What are Alkanes?

Alkanes are saturated hydrocarbons, meaning they contain only single bonds between carbon atoms. They are the simplest class of hydrocarbons and form the basis for understanding organic chemistry nomenclature.

C-C

Single Bonds

Only single C-C bonds

H

Saturated

Maximum hydrogen atoms

-ane

Suffix

Names end in "-ane"

Key Features

  • Hybridization: All carbon atoms are sp3 hybridized
  • Bond Angles: Tetrahedral geometry with 109.5° bond angles
  • Reactivity: Generally unreactive, undergo combustion and halogenation
  • Physical State: C1-C4 are gases, C5-C17 are liquids, C18+ are solids at room temperature
  • Solubility: Insoluble in water, soluble in organic solvents

IUPAC Nomenclature

Basic Naming Rules

  1. Find the longest carbon chain - This determines the parent name
  2. Number the chain - Start from the end nearest to a substituent
  3. Name substituents - Use prefixes like methyl-, ethyl-, etc.
  4. Combine with locant numbers - Position numbers come before substituent names

Structural Isomers

Alkanes with 4 or more carbons can have structural isomers - same molecular formula but different arrangements:

Butane Isomers (C4H10)

  • n-Butane: Linear chain - type butane
  • Isobutane: Branched - type 2-methylpropane

Pentane Isomers (C5H12)

  • n-Pentane: Linear chain - type pentane
  • Isopentane: One branch - type 2-methylbutane
  • Neopentane: Two branches - type 2,2-dimethylpropane
